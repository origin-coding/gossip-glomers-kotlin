# 发布错误手册

发布博客时遇到问题，先查这里。每条按「现象 → 原因 → 处理」写，只记录真实踩过的。

## 图片

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 图片显示成裂图/红色感叹号 | 正文用的是相对路径（`assets/xx.png` 或 `__IMG_01__` 没替换） | 重新上传，把占位符换成平台返回的地址 |
| 掘金图片 403 | 引用了 GitHub `raw.githubusercontent.com` 外链，被防盗链 | 用掘金上传后的 `byteimg` 地址，不要直接外链 |
| 图片糊了 | 原图分辨率低，平台又二次压缩 | 导出时保证宽度 ≥ 1200px，PNG 优先 |
| 图片顺序乱 | 多张图共用一个占位符或漏替换 | 按 `images.md` 的表逐个替换，占位符是唯一编号 |

## 元信息

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 摘要被截断、结尾缺字 | 超过平台上限 | 用 `meta.md` 里的短版本；掘金 100 字、CSDN 120 字 |
| 摘要读起来像"上一篇……" | 自动摘要是正文开头，带上下文 | 手动改成独立可读的一句话：这篇讲什么 + 能学到什么 |
| 标签超过上限被静默丢弃 | 标签数量超限 | 只留 `platforms.toml` 里的 3 个 |
| 栏目没选中、文章没进系列 | 发布时忘了选 | 发布前在编辑器右侧确认栏目名 |

## 格式

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 标题出现两次 | 正文 H1 没删 | 删掉正文第一行 `# ...` |
| 代码块没高亮 | 围栏没写语言 | 补 `kotlin` / `sh` / `json`；`publish-pack` 会统计语言缺失 |
| 表格渲染成一行文字 | 缺分隔行 | 补 `\| --- \| --- \|` |
| CSDN 标题层级整体降一级 | 平台转换器行为 | 不用处理，源文件保持原层级 |
| 外链变成 `link.juejin.cn?target=...` | 掘金自动封装外链 | 正常，不影响点击 |
| 列表项之间的空行被吃掉 | 平台 Markdown 解析差异 | 检查渲染结果，必要时在列表项后补空行 |

## 发布后

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 改了文章但页面没更新 | 平台缓存 | 等待几分钟或强制刷新；掘金可重新保存草稿再发布 |
| 系列互链点不开 | 链接指向还没发布的文章 | 先发后一篇，再回填前一篇的"下一篇" |
| 读者反馈仓库链接 404 | 文章引用了还没推送的路径 | 先 `git push`，再发布文章 |
